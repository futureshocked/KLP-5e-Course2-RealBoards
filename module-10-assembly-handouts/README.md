# Module 10: Assembly, two ways (handouts)

The printable sheets for Module 10, one folder per lecture. Print them before you start at the bench
and fill them in as you go. Where a sheet shows my own results, they are in boxes marked as examples.

| Folder | Lecture | Handouts |
|---|---|---|
| [`L10.1/`](L10.1/) | The bench and the plan for this module | `equipment_list.pdf`: the tools and materials for the module |
| [`L10.2/`](L10.2/) | Test the hotplate before you trust it | `hotplate_test_process.pdf` and `hotplate_test_card.pdf`: how to measure the plate's real temperature, and a card to record it |
| [`L10.3/`](L10.3/) | A first reflow on an old board | `first_reflow_without_a_stencil.pdf`: a practice reflow with paste from the syringe |
| [`L10.4/`](L10.4/) | Assemble the motor board with a stencil and hotplate | `stencil_printing.pdf`, `placement.pdf` (the placement drawing at 3x scale, with every part in placement order) and `reflow_inspect_and_repair.pdf` (reflow, inspection, repairing a bridge, and a record) |
| [`L10.6/`](L10.6/) | Assemble the motor board with a soldering iron | `hand_soldering_not_recommended.pdf`: why hand-soldering this board needs high skill, and what to do instead |

Lecture L10.5, iron practice on a practice board, has no handout.

The board these sheets build is the two-motor capstone as ordered: stage `20-fab-checked` in
[`klp5e-c2-m6-drv8833/`](../klp5e-c2-m6-drv8833/), whose `Gerber/` folder holds the position file.
