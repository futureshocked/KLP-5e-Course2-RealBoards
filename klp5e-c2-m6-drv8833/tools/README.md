# Module 6 checkers

Two Python scripts used from the terminal in Module 6.

- `checknet.py` reads a KiCad netlist and reports what is connected to what (used from lecture L6.6).
- `checkplacement.py` checks the board's placement (used with the board lectures).

In bonus B6.1, copy this whole `tools/` folder into your new project folder, beside the
`.kicad_pro` file. Run them from the project folder, with KiCad closed.
